# 凍蒜大富翁（公開試玩版）

3D 政治諷刺大富翁網頁遊戲：台北、桃園、台中、高雄四張地圖，12 位政壇人物搶地盤、收購、背刺、搶答。

👉 直接玩：https://a1011755-lucky.github.io/dongsuan-monopoly-play/

- 本遊戲是政治諷刺搞笑創作，人物台詞全部虛構，不是本人說過的話；遊戲裡的賄選、搜索、爆炸等事件都是隨機遊戲機制，與真實人物、事件無關。
- 可以同一台電腦輪流玩、跟電腦對打，也可以**線上連線**：一個人按「開新房間」，按「複製邀請連結」傳給朋友，朋友點開連結、按「加入房間」就能一起玩（不用註冊帳號；房主的網頁要一直開著）。
- 人物 3D 模型：Kenney「Mini Characters」（CC0，kenney.nl），授權見 `models/License.txt`。
